# DDJ-SB DJ 0.2.0

## New
- **SAMPLER**: the four SAMPLER pads play one-shot sounds from four slots shared by both decks. Right-click a pad or drop an audio file on it to load a sound (SHIFT + the pads of the controller's second pad bank load the selected track / empty a slot), SHIFT + pad stops a sound, the slots are remembered, the volume is in Audio settings.
- **SLIP mode** (SHIFT + VINYL): the track keeps running in the background during a loop or a scratch and rejoins when you release.
- **QUANTIZE** (SHIFT + SYNC): cue, hot cue and manual loop points snap to the beat grid; the button lights.
- **Plug-and-play audio**: when the DDJ-SB is plugged in while the program runs, master and headphones move to its outputs; when it is unplugged the sound falls back to the default output. A hand-made choice in Audio settings is never overridden.
- **Controller test keeps its results** when the window is closed, lists messages that belong to no known control, and writes a report to Documents/DDJ-SB DJ reports.

## Install
Windows: DDJSBDJ-Setup-0.2.0.exe or DDJSBDJ-0.2.0-portable.exe. macOS 12+: DDJSBDJ-0.2.0-mac-arm64.dmg (Apple silicon) or DDJSBDJ-0.2.0-mac-x64.dmg (Intel).
