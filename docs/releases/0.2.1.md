# DDJ-SB DJ 0.2.1

Small update after testing every control of a real DDJ-SB (72 of 74 controls confirmed OK; the other two, the pitch faders, only lacked a rest in the centre notch during the test).

## Fixed and new
- **Pad-mode buttons** (HOT CUE, AUTO LOOP, MANUAL LOOP, SAMPLER): the screen now follows the controller the moment you press one, before you press a pad.
- **BACK** selects the track that is playing now in the playlist.
- The Controller test lists the mode buttons and BACK.

## Notes
- The physical FILTER FADE button of the DDJ-SB sends no MIDI message, so software cannot see it: use the on-screen FILTER FADE button.
- Everything in 0.2.0 (SAMPLER, SLIP, QUANTIZE, plug-and-play audio, Mac audio watchdog) is included. Install over 0.2.0 or 0.1.0; settings are kept.

## Install
Windows: DDJSBDJ-Setup-0.2.1.exe or DDJSBDJ-0.2.1-portable.exe. macOS 12+: DDJSBDJ-0.2.1-mac-arm64.dmg (Apple silicon) or DDJSBDJ-0.2.1-mac-x64.dmg (Intel).
