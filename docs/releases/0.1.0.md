# DDJ-SB DJ 0.1.0

First public release of **free, dedicated DJ software for the Pioneer DDJ-SB** controller (Windows and macOS).

## What is in it
- Two decks with scrolling waveforms, BPM / key / energy analysis, Harmonic Match, Auto DJ, loops, loop slicer, hot cues.
- A console drawn like the DDJ-SB and a full DDJ-SB mapping: jog wheels, pitch faders (6 / 8 / 10 / 16 / 25 % range), channel faders, HI / MID / LOW / FILTER, FX1 / FX2 with 36 effects (right-click a SELECT button) and LEVEL knobs, performance pads, CUE buttons, FILTER FADE, crossfader, BROWSE and LOAD, LEDs.
- **Real KEY LOCK** (master tempo).
- **Headphone cue**: a deck plays in the headphones only while its CUE button is on; HEADPHONES MIX blend; speakers and headphones time-aligned.
- **First-start calibration wizard** and a **Controller test** that records all 74 controls.
- SHIFT shortcuts for software MASTER LEVEL (SHIFT + FX LEVEL) and HEADPHONES LEVEL (SHIFT + HEADPHONES MIX), because the controller's own two knobs are analog.

## Known limits
- Tested on a real DDJ-SB for most controls; the auto loop and manual loop pads and the LOAD / BACK buttons are mapped but not yet confirmed. Slip, quantize and deck 3 / 4 are not mapped.
- The app is not code-signed (Windows) or notarised (macOS): see the install notes.

## Install
Windows: `DDJSBDJ-Setup-0.1.0.exe` (offers to install Pioneer's DDJ-SB driver, which Windows needs for the controller's MIDI) or `DDJSBDJ-0.1.0-portable.exe`. macOS 12+: `DDJSBDJ-0.1.0-mac-arm64.dmg` (Apple silicon) or `DDJSBDJ-0.1.0-mac-x64.dmg` (Intel); right-click the app and choose Open the first time.

The installer includes Pioneer DJ's own DDJ-SB driver 1.100 (signed by Pioneer DJ Corporation); see NOTICE.md.
